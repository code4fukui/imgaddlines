# imgaddlines

画像にカスタマイズ可能なグリッド線を追加するための、シンプルなブラウザベースのツールです。

## デモ
https://code4fukui.github.io/imgaddlines/

## 機能
- **簡単な画像読み込み:** 画像ファイルをドラッグ＆ドロップするか、デフォルトのサンプル画像を使用できます。
- **カスタマイズ可能な線:** 画像に水平または垂直の線を追加できます。
- **ライブプレビュー:** コントロールを調整すると、変更が即座に反映されます。
- **微調整:** スライダーを使用して、線の間隔、太さ、オフセットを正確に調整できます。
- **PNGエクスポート:** 線が追加された最終的な画像をPNGファイルとしてダウンロードできます。

## 使い方
1.  **画像を読み込む:** ページ上の任意の場所に画像ファイルをドラッグ＆ドロップするか、デフォルトで読み込まれるサンプル画像をそのまま使用します。
2.  **線を調整する:** 画面上のコントロールを使用して線を変更します。変更はリアルタイムでプレビューされます。
    *   **方向:** デフォルトでは垂直線です。チェックボックスをオンにすると水平線に切り替わります。
    *   **スライダー（上から順に）:**
        *   **間隔:** 線と線の間隔を調整します。
        *   **太さ:** 線の太さを調整します。
        *   **オフセット:** 最初の線の開始位置を調整します。
3.  **画像を保存する:** 「save」ボタンをクリックして、編集した画像をダウンロードします。ファイルは `filtered-image.png` として保存されます。
