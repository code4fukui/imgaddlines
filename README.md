# imgaddlines

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A simple, browser-based tool for adding customizable grid lines to images.

## Demo
https://code4fukui.github.io/imgaddlines/

## Features
- **Easy Image Loading:** Drag and drop any image file or use the default sample image.
- **Customizable Lines:** Add horizontal or vertical lines to your image.
- **Live Preview:** Instantly see changes as you adjust the controls.
- **Fine-Tuning:** Use sliders to precisely control line spacing, width, and offset.
- **PNG Export:** Download the final image with lines as a PNG file.

## How to Use
1.  **Load an Image:** Drag and drop your image file anywhere on the page, or simply use the sample image that loads by default.
2.  **Adjust the Lines:** Use the on-screen controls to modify the lines. Changes are previewed in real-time.
    *   **Orientation:** Lines are vertical by default. Check the box to switch to horizontal lines.
    *   **Sliders (from top to bottom):**
        *   **Spacing:** Controls the distance between each line.
        *   **Width:** Controls the thickness of the lines.
        *   **Offset:** Controls the starting position of the first line.
3.  **Save Your Image:** Click the "Save" button to download the modified image. The file will be saved as `filtered-image.png`.
